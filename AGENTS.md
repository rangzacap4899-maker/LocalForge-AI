# Instructions for AI agents

Read `AI_HANDOFF.md` completely before changing this repository. It contains the
current architecture, hardware constraints, test commands, Git publishing flow,
known failure modes, and protected user changes.

After a material change, update `AI_HANDOFF.md` so the next agent can continue
without relying on chat history. Never commit the existing `CMakeLists.txt`
modification unless the user explicitly asks for it.
